# ailicili

**面向 Bilibili 的多端视频与直播观看应用**

浏览热门视频和推荐直播、搜索用户投稿与直播间、播放内容、收藏视频或直播间、继续本地观看记录，并在 Windows 上使用 Bilibili 账号登录。

## 功能

- 视频优先首页，可浏览 Bilibili 热门视频。
- 支持用户投稿视频关键词搜索。
- 支持 Bilibili 推荐直播发现、真实关键词搜索和结果分页。
- 支持直播间详情、HLS/FLV 播放、协议切换、断流重连和直播清晰度状态。
- 支持 `BV...` 与 `av...` 视频详情、分 P 信息和视频播放。
- 支持 DASH 分离音视频播放、可操作清晰度切换、播放进度、倍速、音量、画中画和全屏。
- 音量、静音状态和倍速会在重启后保持。
- 支持单击画面暂停或继续，双击切换全屏。
- 支持视频与直播间本地收藏、收藏页、历史页、历史清空和分 P 续播。
- 播放页取消收藏采用单击提示、双击取消，减少误触。
- 自动保存本地播放历史，便于继续观看。
- 支持视频只读评论侧栏，包括热门/最新排序、分页、回复展开、图片灯箱、表情和异常重试。
- 支持亮色、暗色主题与中英文界面。
- Windows 支持系统托盘、无边框标题栏和命令面板。

## 账号与画质

Windows 版支持 Bilibili 二维码登录和手机短信验证码登录。

- 登录状态保存在 Windows 系统凭据库中。
- 登录后可使用账号相关的视频访问能力。
- 默认请求当前账号和视频可用的最高画质。
- 支持在视频实际返回的 DASH 画质之间切换，并保留播放进度与音视频同步。
- 支持在直播间返回的实际画质之间切换；未登录时保留入口并提示登录，不发送越权请求。
- 未登录或登录失效时，应用会提示登录后可能解锁更高画质。
- 实际可播放画质和直播协议由 Bilibili 根据账号、内容和平台策略返回。
- 应用不会绕过付费、账号权限或区域限制。

当前暂不提供 Cookie 粘贴、密码登录或网页登录。

## 当前限制

> [!NOTE]
> 当前版本以 Bilibili 用户投稿视频、DASH 播放和 Bilibili 直播为主，部分能力仍在开发中。

- 仅支持 Bilibili 用户投稿视频与直播，暂不支持番剧、影视和充电专属内容。
- 暂不支持 Android 播放和 Android 账号登录。
- 暂不支持 Douyin、Huya 等其他直播平台。
- 暂不支持视频弹幕、直播弹幕、评论发布、点赞、投币、平台收藏夹和云端历史。
- 暂不支持视频下载与离线缓存。
- Windows 视频使用软件解码以规避 WebView2 窗口拖动时的硬件解码冻结；高分辨率或高码率内容的 CPU 占用会高于硬件解码。

## 本地运行

当前项目仍处于开发阶段，尚未提供正式安装包。

### 环境要求

- Node.js 18 或更高版本
- pnpm 9 或更高版本
- Rust stable
- Tauri 2 对应平台依赖
- Windows 需要 WebView2

### 启动应用

```bash
pnpm install
pnpm tauri dev
```

### 构建前端

```bash
pnpm build
```
